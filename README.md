# contaonline — الكرنه على الويب

نسخة مستقلة ومحلية أولًا من التطبيق المعتمد. نُفّذت دفعات PWA والحسابات والتفعيل والإدارة وسياسة التثبيتات والنسخ السحابي الاختياري. الحالة الحالية: مراجعة واختبارات قبل الإنتاج؛ قبول iPhone الحقيقي وإذن النشر لم يتمّا.

المصدر ثابت عند feat/approved-seller-app @ 1efb01fc1cd7bc62670510e57c6158734ad4bf05. 52 ملفًا منقولًا بقائمة سماح وبصمات؛ الكود الأصلي وأندرويد وتفعيله ومفاتيحه وworkflows الخاصة به دون تعديل. التكييف في web/ وتحويلات build مستقلة.

## التثبيت والفحص

Node.js 24.22.1 وnpm 11.19.1؛ Fastify 5.12.7 وlockfile. تحقق دعم Node/Fastify موثق في docs/OPERATIONS.md.

```sh
npm ci --ignore-scripts
npm run check
npx playwright install --with-deps chromium webkit
npm run test:e2e
BROWSER_ENGINE=webkit npm run test:e2e
npm run test:pdf
```

check يشغّل البصمات وbaseline الستة وlint/typecheck والبناء والاختبارات. اختبارات المتصفح لا تغني عن iPhone فعلي. عند قيود Temp في ويندوز يمكن ضبط TEST_TMPDIR إلى مجلد اختبار خاص قابل للكتابة؛ لا تغير أهداف البيانات الفعلية.

## مراجعة محلية خاصة

```sh
npm run staging:key
npm run bootstrap-admin -- your-admin-username
```

الأمر الثاني ينشئ مفاتيح خدمة مستقلة وقاعدة محلية وحساب إدارة عشوائيًا داخل private/service. معلومات الوصول وMFA تظهر في ملف bootstrap-receipt.json الخاص فقط؛ انقلها بأمان وسجّل MFA ثم احذف الإيصال. لا ترسلها في المحادثة أو تضعها في Git. لا يوجد حساب إداري افتراضي.

اضبط STAGING_ACCESS_KEY_FILE وSERVICE_CONFIG_FILE إلى مسارات الملفين الخاصين ثم:

```sh
npm run migrate
npm start
```

الخادم يستمع على 127.0.0.1:4318 فقط، وبوابة مراجعة تحمي كل routes/assets/API. /admin/ للإدارة، /app/ للمحل، / للاختيار بين أندرويد وآيفون. رابط APK معطل حتى تضبط الإدارة المصدر الرسمي والإصدار. إعداد NODE_ENV=production مرفوض عمدًا، وreadiness يعيد 503 حتى إكمال القبول. لا تخدم dist باستضافة عامة مباشرة.

## السلوك المعتمد

- أول تفعيل متصل يبدأ الاشتراك ذريًا؛ إعادة التثبيت والاستعادة لا تعيدان المدة. التجديد من النهاية السارية أو وقت الاعتماد بعد الانتهاء.
- مفتاح جديد مع غياب نشاط متعارض يُقبل آليًا ضمن المعدل. نزاع نشاط مسجل يبقى للمراجعة. القديم يُرصد دون استعادة سلطة الرفع. لا حظر نهائي آلي لإشارات ضعيفة.
- بعد انتهاء التطبيق: دخول محلي وعرض وتصدير فقط. لا حذف للبيانات. الحظر لا يصل لجهاز أوفلاين فورًا، ولا توجد حماية مطلقة من تعديل العميل أو الساعة.
- النسخ خدمة مستقلة وبموافقة؛ outbox ذري ودلتا وACK دائم ونسخ بإصدارات. لا رفع محاسبة في الوضع المحلي فقط. الاستعادة بمعاينة وتأكيد ونسخة أمان وتوقف الرفع حتى المراجعة.
- بعد انتهاء خدمة النسخ: تنزيل مأذون 30 يومًا وتنبيه حساب قبل مهمة حذف مدققة؛ بيانات الجهاز مستقلة. جدول يومي/أسبوعي/أثناء الفتح، ولا وعد بتشغيل iOS وهو مغلق.

راجع docs/HANDOFF.md وdocs/TEST_REPORT.md وdocs/RELEASE_ACCEPTANCE.md للتغطية والفجوات، وdocs/IPHONE_ACCEPTANCE.md لقائمة الاختبار على هاتف فعلي. النشر وVPS/DNS/Nginx وتغيير visibility يحتاج كل منها إذنًا منفصلًا. نوصي بمستودع خاص؛ لم نغيّر حالته.
