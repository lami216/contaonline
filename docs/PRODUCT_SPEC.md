# مواصفات المنتج المعتمدة
هذا سجل القرارات الفعلية، وليس ادعاء اكتمال الميزات.
- المنتج: موقع للهاتف يوجه إلى APK الرسمي الحالي أو نسخة الويب/PWA؛ لا رابط تنزيل APK مختلق ولا تغيير أندرويد.
- الويب محلي أولًا: المحاسبة وIndexedDB دون اتصال بعد تجهيز الموارد وأول تفعيل، ضمن صلاحية التصريح.
- الحفاظ على المحاسبة والربح التاريخي واتجاهات الدين والتعديلات والإلغاءات، وأدوار المحل والعربية/الفرنسية والمظهرين.
- الحساب الإداري/اشتراك الخدمة مستقل عن مستخدمي المحل المحليين.
- لوحة إدارة فعلية مع MFA، باقات وأسعار إدارية ودفع يدوي وتفعيل وتجديد وتثبيتات وaudit.
- نسخ سحابي اختياري منفصل: صلاحية + موافقة قبل أي رفع؛ استئناف وإقرار دائم وعزل واستعادة كاملة.
- مدة الاشتراك تبدأ ذريًا عند أول تفعيل أو تاريخ إداري صريح، ولا تبدأ بسبب إعادة التثبيت أو الاستعادة.
- تجديد الساري يضاف إلى نهايته؛ المنتهي يبدأ عند اعتماد الإدارة.
- تصريح الأوفلاين قد يستمر إلى نهاية الاشتراك؛ الحظر ليس فوريًا دون اتصال ولا حماية ساعة مطلقة.
- بعد الانتهاء: عرض محلي وتصدير بعد مصادقة محلية؛ لا كتابة جديدة أو تعديل أو استيراد أو حذف بيانات.
- انتهاء خدمة النسخ مستقل عن ترخيص التطبيق. مهلة النسخ 30 يومًا مع تنزيل مأذون وتنبيه داخل الحساب قبل الحذف المدقق، لا حذف للمحلي.
- التثبيتات: مفتاح جديد ليس مخالفة، ويمكن اعتماده تلقائيًا عند غياب نشاط متعارض، وفق السياسة المحددة في INSTALLATION_POLICY.
- خارج الإصدار الأول: عدة أجهزة كتابة متزامنة؛ جهاز مشاهدة تجهيز معماري فقط؛ دفع إلكتروني؛ متاجر التطبيقات.
- لا SaaS مدفوع أو Redis أو خدمات متعددة دون حاجة وإذن؛ لا نشر أو تعديل VPS/DNS/Nginx دون إذن منفصل.
