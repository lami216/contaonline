# مراجعة دفعة الحسابات والتفعيل

دفعة مستقلة بعد `ff8c074dd67ba4e04e8f8e52bc5e775baa7d58a6` (CI ناجح: https://github.com/lami216/contaonline/actions/runs/39955617447).

المنفذ: SQLite WAL وforeign keys وFULL synchronous؛ حسابات خدمة منفصلة، scrypt، MFA إداري TOTP مع منع إعادة استخدام الرمز، أسرار MFA مشفرة بمفتاح خدمة خارج الموقع؛ جلسات HttpOnly/SameSite وCSRF وrate limits؛ bootstrap محلي بمعلومات عشوائية داخل ملف خاص دون كلمة مرور افتراضية؛ استرداد إداري محلي برمز وحيد الاستعمال؛ إدارة العملاء والباقات والدفع اليدوي والتجديد وحالة الترخيص وقرارات التثبيت وAPK؛ سجل audit غير قابل للتعديل والحذف عبر SQL العادي.

التفعيل يستخدم إثبات مفتاح P-256 بتحدٍ قصير مرتبط بالحساب والجلسة والغرض. المعاملة تثبّت بداية واحدة وجيل كاتب واحد، والتوقيع يصدر قبل commit. إعادة التثبيت بعد غياب النشاط تحفظ نهاية المدة وتسمح آليًا؛ النشاط الحديث يعلق الطلب الجديد. القديم المعتمد يبقى للرصد، ولا يستعيد سلطة الرفع أو تصريحًا جديدًا بمجرد عودته. التداخل المستمر ينشئ حادث مراجعة ويوقف سلطة الرفع دون حذف البيانات أو حظر نهائي آلي. كل تبويبات المفتاح نفسه تشترك في صف presence واحد.

آلة الحالات واختباراتها عُرضت في `INSTALLATION_POLICY.md` بالدفعة الأولى وقبل تنفيذ هذه الوحدة. القيم التشغيلية قابلة للضبط: heartbeat مرئي 60 ثانية، lease 300 ثانية، مهلة تداخل 300 ثانية، 3 تغييرات كاتب آلية في 24 ساعة. لا يستخدم وقت المعاملات أو رفعها كدليل تزامن. session الخدمة المنتهية لا تنهي التصريح المحلي. الحظر لا يصل لجهاز أوفلاين فورًا.

النتائج المحلية: `npm run check` نجح؛ 52 بصمة، baseline الستة، lint، strict/checkJs للكود الجديد ضمن tsconfig، build، و11 اختبارًا نجحت دون فشل أو تجاوز. من بينها سباق فعلي بعاملين واتصالين SQLite مستقلين؛ نتيجة واحدة ناجحة وطلب ثانٍ pending وفترة واحدة. أنواع صفوف SQL وأجسام الطلبات حدود ديناميكية تتأكد منها قيود القاعدة وJSON schemas؛ لا ادعاء static typing شامل لها أو لواجهة المصدر.

أضيف اختبار متصفح لتسجيل دخول الإدارة بـMFA ثم تفعيل عميل فعلي، إلى جانب اختبارات PWA الثمانية السابقة. يُشغّل عبر CI لأن الشبكة المحلية لمتصفح بيئة التنفيذ كانت ممنوعة. نتيجة CI الخاصة بهذه الدفعة تُسجّل بعد اكتماله.

ما زال خارج قبول هذه الدفعة: النسخ السحابي والاستعادة الكاملة، اختبار iPhone الحقيقي، اختبار بصري نهائي لـPDF العربي، races تحديث PWA، استنفاد quota حقيقي، القياس التشغيلي، وجاهزية الإنتاج. إدارة metadata محدودة بصفحات أولية 500 سجل وتحتاج تحسين pagination قبل التشغيل الموسع. مفاتيح الدوران العامة ممكنة في config؛ أدوات دوران وتشغيل وتعافٍ كاملة تحتاج توثيقًا واختبارًا إضافيين. لا SaaS ولا Redis ولا نشر.
