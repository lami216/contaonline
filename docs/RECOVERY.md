# الاستعادة والتعافي
## الحالة الفعلية
المرحلة الأولى تثبت قابلية إعادة بناء موارد المصدر واختبارها؛ لم يُنفذ بعد استرجاع سيرفر إنتاج أو نسخة سحابية.
النسخ المحلية الحالية من المصدر موجودة في baseline؛ لا ادعاء اختبارها على iPhone في هذه الجولة.

## معايير التنفيذ والقبول
- تخزين origin خاص بكل محل، بدون حذف DB عند خطأ فتح/schema أو تسجيل خروج.
- قبل migration أو restore: snapshot أمان كاملة تشمل مستخدمي المحل المتوافقين، دون مفاتيح خدمة أو تراخيص Android.
- preview وتحقق حجم/schema وعلاقات وموافقة قبل استبدال محل محلي؛ تسجيل الدخول وحده لا يكتب فوقه.
- رفض استعادة قديمة فوق بيانات أحدث دون مراجعة؛ generation/cursors تمنع إعادة رفع الأحداث المقبوضة.
- النسخة لا تعيد فترة الاشتراك أو سلطة الكاتب أو جلسات الإدارة.
- سيرفر SQLite: backup API أو إجراء متسق مع WAL، وليس نسخ ملف DB منفردًا أثناء كتابة؛ نسخ خارج السيرفر مشفرة بمفتاح مستقل وخطة استعادة فعلية.
- اختبار clean install: restore ثم مطابقة مخزون وديون وحسابات ومستندات وصلاحيات، وليس تنزيل JSON فقط.
- مهلة خدمة النسخ 30 يومًا، مع تنزيل مأذون وتنبيه داخل الحساب وحذف بjob مدقق ومختبر. المحلي لا يحذف.
- عند امتلاء/فشل كتابة أو رفع: لا إعلان نجاح ولا إسقاط outbox؛ رسائل واضحة واستئناف.
