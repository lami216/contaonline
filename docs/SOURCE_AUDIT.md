## ما يمكن نقله
- approved-runtime كمرجع واجهة ومنطق محاسبي، مع تثبيت hashes قبل التعديل.
- سكربتات التحقق الستة وتبعياتها المباشرة فقط، وموارد الشعار والخطوط ورخصها.
- الأجزاء ذات الصلة من وثائق السلوك في مجلد مرجعي، مع التمييز عن وثائق contaonline الجديدة.
- لا نقل لتاريخ Git الأصلي أو Expo أو approved-android أو workflows APK/Pages أو مفاتيح أو حسابات أو قواعد مستخدمين.

## التفعيل الحالي
- الترخيص `.alkarna-license` بتوقيع ECDSA P-256/SHA-256 وبصيغة V1/V2، مع مفاتيح تحقق عامة فقط داخل Android.
- كود الجهاز مشتق من ANDROID_ID بصيغة AKD؛ الحالة المحلية خارج IndexedDB ونسخ المحل، محمية بمفتاح HMAC في Android Keystore.
- الترخيص المؤقت يبدأ عند التثبيت، وسجل IDs المستهلكة لا يعاد ضبطه بالتجديد العادي.
- NativeHost يمنع تحميل الموارد والعمليات المحمية في المضيف، والغلاف لا يملك إذن الإنترنت.
- activation.js يعتمد على NativeHost؛ ليس تفعيل ويب.
- في المتصفح دون NativeHost يعود readSetupIdentity بقيمة null، ويتيح المسار الحالي إنشاء مالك محلي. لذلك نشره كما هو لا يحمي الخدمة المدفوعة.
- لا تعديل لهذا النظام أو إصدار تراخيص أو APK جديد ضمن المشروع.

## تنفيذ المرحلة الأولى بعد اعتماد المالك
نقل 52 ملفًا بالبايتات الأصلية من Git SHA المحدد، دون استخدام تحويل CRLF المحلي. قائمة السماح الصريحة تشمل source/destination/bytes/sha256/gitBlob في resources/source-manifest.json. الخطوط نقلت من assets/fonts إلى approved-runtime/assets مع رخصة OFL؛ SQL مولد من حزمة npm مثبتة ومتحقق SHA-256، ورخصته تطابق المصدر.
استبعدت activation.* وnative-adapter.js/native.css وAndroid وExpo وworkflows الأصلية وتاريخ المصدر. ملف assets/package.json جديد للتوافق مع اختبار SQL CommonJS؛ ليس تغييرًا للموارد الأصلية.
الدفعة CI فحص/بناء دون نشر، وبوابة artifact مغلقة. سياسة المراجعة الإدارية لكل مفتاح في تقرير التدقيق السابق ملغاة؛ تعتمد سياسة المالك المصححة في DECISIONS وINSTALLATION_POLICY.
